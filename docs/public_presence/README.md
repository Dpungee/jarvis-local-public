# Public Presence foundation

These records define the non-live foundation for a future JARVIS Public
Presence. They are security and operator-control documents, not authorization
to connect to any platform.

- `BASELINE.md` is a sanitized template for an approved release baseline.
- `THREAT_MODEL.md` identifies public-input, privacy, authority, reliability,
  account, and reputation risks and their required controls.
- `PROHIBITED_ACTIONS.md` is the permanent denylist for the public security
  domain.
- `RECOVERY_RUNBOOK.md` defines safe stop, evidence preservation, backup,
  isolated restore, rollback, and credential-revocation procedures.
- `EXIT_GATE_CHECKLIST.md` is the fail-closed checklist that must be completed
  before any account connection, listener, or external communication.

Canonical identity and conduct contracts live at repository root in
`PUBLIC_SOUL.md`, `PUBLIC_PROFILE.json`, and `PUBLIC_POLICY.md`.

Public Presence remains disabled. This directory must never contain credentials,
private-memory exports, operator conversations, platform tokens, or live account
data.
